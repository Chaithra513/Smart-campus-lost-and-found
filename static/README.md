# Smart Campus Lost and Found

A web-based Lost and Found management system designed for college campuses.

The application provides a centralized platform where students can report lost or found items and browse existing reports.

## Features

- Report lost items
- Report found items
- Browse lost and found items
- Search items by keyword
- Filter items by location
- Filter items by Lost or Found status
- Edit submitted reports
- Delete reports
- Mark items as Resolved or Claimed
- Store item details using a database
- Responsive and user-friendly interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
